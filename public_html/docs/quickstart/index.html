Quickstart

Create an account, send your first request in the Tester, and save it.

On this page1. Create an account2. Send your first request3. Save itWhere to next

This guide takes you from a fresh account to a saved request in a few minutes. All you need is an API endpoint to call — a public one such as https://httpbin.org/get works fine.

1. Create an account

  1. Open the registration page and sign up with your email, or use Google sign-in.
  2. Confirm your details to finish registration.
  3. You will land on the dashboard, which summarises your recent activity.

2. Send your first request

  1. Open the Tester.
  2. Leave the protocol set to REST and the method set to GET.
  3. Enter a URL, for example https://httpbin.org/get.
  4. Press Send. The response — status, timing, headers, and body — appears alongside the request.

Try a request with a body next. Switch the method to POST and send some JSON:

json
{
  "name": "Ada",
  "role": "engineer"
}

3. Save it

Once a request does what you want, save it so you can re-run it, assert on it, or add it to a collection.

  1. Give the request a name.
  2. Save it. It now appears in your saved requests and is available to Collections.
Values you will reuse — a base URL, a token — belong in an environment as {{variables}}, not typed inline. See Environments and variables.

Where to next

  • Add pass/fail checks with assertions.
  • Chain saved requests together with collections.
  • Watch an endpoint over time with monitors and alerts.
