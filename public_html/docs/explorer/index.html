Explorer

Point an autonomous agent at an MCP server with a goal; see the path it took and what it found.

On this pageRunning an explorationSafe modeReading the result

The Explorer (the Agent Explorer) turns the agent loop into a discovery and red-team instrument. You give it an MCP server and a goal; an AI model pursues that goal by calling the server's tools, and Spi records the path it took, the capabilities it found, and every destructive tool it reached for. Open it at Explorer. It is part of Spi's MCP testing suite.

Running an exploration

  1. Enter the MCP server URL, e.g. https://mcp.example.com/mcp.
  2. Write a goal in plain English, e.g. "Find the current weather in Sydney".
  3. Leave Safe mode on (the default) so the agent refuses side-effecting tools.
  4. Pick Max steps (4–12) to bound how long the agent runs.
  5. Press Explore.

Safe mode

In safe mode the agent will not execute a tool that looks destructive — a blocked attempt is recorded as a finding, not carried out, so pointing the Explorer at a real server is safe. Turn safe mode off only against a throwaway target: the agent may then call tools that change or delete data.

Reading the result

When the run finishes you get:

  • A verdict — goal met or incomplete — with the tool-call count and how many tools the server exposed.
  • The agent's final answer, if it reached one.
  • Findings — blocked destructive attempts, injection-scanner hits on the discovered tools, and the list of side-effecting tools the server exposes, with an overall risk level for the surface.
  • The path — a step-by-step transcript of the agent's thinking, each tool call with its arguments, and the result returned (or why it was blocked).
Explorer discovers a server's tool surface once. To catch changes to that surface over time, set up an MCP drift monitor; to record and firewall an agent's live traffic against a server, use the Recorder.
