What is Spi?

A multi-protocol API testing and monitoring platform for humans and agents.

On this pageProtocols it coversWho it is for

Spi is a multi-protocol API testing and monitoring platform. You send requests, assert on the responses, chain requests into collections, schedule those collections as monitors, and share the results — all from one place, and all without leaving the browser.

What sets Spi apart is breadth. Most tools speak plain HTTP; Spi also speaks the protocols agents and back-ends actually use, and it treats the Model Context Protocol (MCP) as a first-class citizen rather than an afterthought.

Protocols it covers

The Tester sends requests over these protocols directly:

  • REST / HTTP — any method, headers, query params, and a request body. GraphQL and SOAP are sent this way too: a GraphQL query is a POST with a JSON body, and SOAP is a POST with an XML body.
  • MCP — the Model Context Protocol, over Streamable HTTP.
  • A2A — Agent-to-Agent, including fetching an agent card.
  • gRPC — unary calls over HTTP/2, with the request message described as JSON.
  • MQTT — publish and subscribe against a broker.
  • AMQP — publish and consume against a broker such as RabbitMQ.

Beyond the Tester, Spi captures inbound webhooks at a public URL and runs a full MCP testing suite — a gateway, a flight recorder, a mock server, replay, and a policy firewall. See MCP testing.

Who it is for

  • Developers who want a fast, scriptable way to exercise an endpoint and pin down its behaviour.
  • Teams running scheduled monitors and status pages against production and staging.
  • Anyone building or integrating AI agents who needs to test, record, mock, and guard MCP servers.
