Navigating Spi

A map of every item in the workspace menu and what each one is for.

On this pageThe workspace menu

Once you sign in, the left-hand sidebar is your workspace menu — the way you move between everything Spi does. This article is a one-line map of each item; follow the links for the full guide to any of them.

Toggle the sidebar with the menu button in the top bar, and jump anywhere fast with the command palette (Cmd/Ctrl + K).

The workspace menu

Home

The dashboard you land on after signing in. It greets you, links out to the main areas, and lists your most recent reports. See Home.

Tester

Compose and send a single request over any supported protocol — REST, MCP, A2A, gRPC, MQTT, AMQP — and inspect exactly what came back. See Sending requests.

Collections

Chain saved requests into ordered steps, thread variables between them, and run the whole flow for a single pass/fail. See Collections.

AI Lab

AI-assisted authoring and MCP security scanning: draft a request from plain English, explain a response, generate assertions, diagnose a failing request, and scan MCP tools for prompt-injection. See AI Lab.

Explorer

Point an autonomous agent at an MCP server with a goal and watch the path it takes, the capabilities it finds, and the destructive tools it reaches for. See Explorer.

Monitors

Run a collection on a schedule, track uptime, and get alerted when its status changes. See Monitors and alerts.

Webhooks

Capture inbound HTTP callbacks at a public URL, trigger collection runs from events, run datasets, and profile performance. See Webhooks, datasets, and profiling.

Recorder

A relay that sits between an agent and an upstream MCP server, recording every exchange and enforcing a firewall policy. See Recorder.

Mocks

Serve a fake MCP server at a URL you can develop against — built by hand or seeded from recorded traffic. See Mocks.

Reports

Browse, compare, and share the inspection reports your runs produce, and publish public status pages. See Reports and sharing.

Spi

The built-in AI assistant. Ask it how to build a request, understand a protocol, or debug a failure. See Spi assistant.

Administrators also have a separate Admin area — users, organisations, monitoring, and catalog — which replaces the workspace menu while you are in it, with one link back out. It is only visible to admin accounts.
