Spi assistant

The built-in AI chat that helps you build requests, understand protocols, and debug failures.

On this pageSetting it upUsing it

Spi is the built-in AI assistant — your API testing companion. Ask it how to test something, what a protocol expects, or why a request is failing, and it answers in context. Open it at Spi.

Setting it up

The assistant runs on your own SCX account, so add your SCX API key before you start: go to Profile, open the Settings tab, and under SCX AI Integration paste your SCX API Key and pick an AI Model. Until a key is saved, the chat shows a prompt to add one instead of the message box.

Using it

  1. Open Spi.
  2. Type a question, or click one of the starter suggestions.
  3. Continue the conversation — the assistant keeps the thread's history for context.

The starter suggestions show the kinds of thing it is good at:

  • "How do I test an MCP server?"
  • "Set up environment variables for staging and prod."
  • "Why is my request returning 401?"
  • "Show me a gRPC request example."
Spi answers questions in chat; to have an AI actually draft a request, generate assertions, or scan MCP tools, use AI Lab, which runs on the same SCX key.
