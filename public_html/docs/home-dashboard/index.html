Home

The dashboard you land on: shortcuts to every area and your recent reports.

On this pageThe shortcut gridRecent reports

Home is the dashboard you land on after signing in. It is a launchpad: a greeting, a grid of shortcuts to the main areas of the app, and a list of the reports you generated most recently.

The shortcut grid

The cards near the top jump straight to the areas you use most:

  • Collections — your saved requests and the collections that run them in order.
  • Tester — send REST, MCP, A2A, gRPC, MQTT, and AMQP requests, with environments for reusable {{variables}}.
  • AI Lab — author requests from plain English, explain responses, generate assertions, and scan MCP tools for prompt-injection.
  • Monitors — run a collection on a schedule and get alerted when it starts failing.
  • Reports — saved conformance grades, security scans, and agent runs.
  • Spi — the built-in assistant for building requests and debugging failures.

Recent reports

Below the grid, Home lists your five most recent reports — each with its type (conformance, security, agent run, collection run, MCP drift, and so on), the connector or target it ran against, a one-line summary, and how long ago it ran. Click any row to open Reports; use View all to see the full history.

When you have not run anything yet, this area is empty and points you at AI Lab to generate your first report.

New to Spi? The quickstart takes you from a fresh account to a saved request in a few minutes.
