Account security

Two-factor authentication, active sessions, API keys, and the security activity log.

On this pageTwo-factor authenticationActive sessionsAPI keysSecurity activity log

Everything that protects your account lives under Profile → Account: two-factor authentication, the list of devices you are signed in on, your API keys, and a log of security-relevant events. Open Profile from the account menu (top right) and pick the Account tab.

Two-factor authentication

Two-factor authentication (2FA) adds a time-based one-time code (TOTP) from an authenticator app on top of your password. Enrolment is two steps:

  1. Scan the QR code with your authenticator app, or enter the setup key by hand.
  2. Confirm a code from the app to prove it is working and finish enabling 2FA.

When 2FA is enabled you are shown a set of one-time recovery codes — displayed once, so save them somewhere safe. Each lets you sign in if you lose the authenticator. Disabling 2FA requires your password, so a hijacked session cannot quietly turn it off.

Active sessions

The active sessions list shows every device you are currently signed in on. If you see one you do not recognise — or you signed in on a shared machine and forgot to sign out — you can sign out other devices in one action, ending every session except the one you are using.

API keys

Your personal API keys are managed here too — creating, scoping, and revoking them. For how keys work and what they can drive, see API keys & programmatic access.

Security activity log

The account keeps an append-only log of security-relevant events — sign-ins, failed sign-ins, password changes, and key creation and revocation — each with the IP address and time. Review it periodically for anything you do not recognise. See Usage & account activity for the full list of audited events.

If you are locked out — a lost authenticator with no recovery codes left — an administrator can reset your 2FA and sign out your sessions as part of account recovery.
